# qna-project

Spring Boot로 Q&A 게시판의 기본 흐름을 연습한 백엔드 프로젝트입니다. 질문과 답변을 중심으로 웹 애플리케이션의 계층 구조, 라우팅, 데이터 처리 흐름을 익히는 데 초점을 두었습니다.

## 주요 내용

- Gradle 기반 Spring Boot 프로젝트 구성
- 질문/답변 도메인 구조 설계 연습
- Controller, Service, Repository 계층 분리
- 서버 사이드 웹 애플리케이션의 요청-응답 흐름 학습

## 기술 스택

- Java
- Spring Boot
- Gradle
- Git / GitHub

## 프로젝트를 통해 익힌 점

이 프로젝트에서는 단순히 기능을 만드는 것보다 Spring Boot 프로젝트가 어떤 구조로 동작하는지 이해하는 데 집중했습니다. 라우팅, 비즈니스 로직 분리, 빌드 도구 사용, 기본적인 백엔드 개발 흐름을 실습했습니다.

## 실행 방법

```bash
./gradlew bootRun
```

Windows 환경에서는 아래 명령어를 사용할 수 있습니다.

```bash
gradlew.bat bootRun
```
